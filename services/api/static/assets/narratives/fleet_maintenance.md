# ร่าง narrative — บริษัทขนส่ง (โจทย์ PLAN-0086 : ฉบับปรับแก้เลอะ)

> **สถานะ:** ฉบับจำลองบทสัมภาษณ์ลูกค้า (Cray-modified) — มีการเบลอตัวเลข เพิ่มเรื่องนอกประเด็น และปรับลำดับการเล่าให้ข้ามไปมาตามธรรมชาติของเจ้าของกิจการ

---

คุณเชื่อป่าวว่าเรื่องซ่อมรถนี่ทำผมความดันขึ้นเลย วันก่อนเพิ่งไปหาหมอมา หมอสั่งลดเค็มด่วน บอกให้พักผ่อนบ้าง... คือผมทำรถรับจ้างมานานนะพี่ ตั้งแต่รุ่นพ่อละ ตอนนี้รถหัวลากก็มีอยู่สิบกว่าคัน หกล้อก็... น่าจะยี่สิบปลายๆ มั้ง วิ่งสายแหลมฉบังกับทางอีสานเป็นหลักเลย

ปัญหาที่ปวดหัวสุดคือเวลามันเสียกลางทางเนี่ยแหละ อย่างเดือนก่อน หกล้อทะเบียนจำไม่ได้ละ ไปเพลาขาดแถวๆ ปากช่อง... โอ๊ย งานงอกสิครับ ของก็กระเบื้องเต็มคันรถของห้าง ต้องรีบส่งเข้าศูนย์กระจายสินค้าโคราชให้ทันสี่โมงเย็น ต้องไปวิ่งเต้นจ้างรถคอกแถวนั้นมาถ่ายของ โดนค่าเช่าไปเป็นหมื่น แล้วค่าซ่อมอีก ไม่รู้กี่หมื่น บิลยังมาไม่ครบเลยมั้ง

เนี่ย ช่วงนี้คนขับก็หายากนะ ทิ้งงานกันดื้อๆ ก็มี บ่นว่าเศรษฐกิจไม่ดี ล่าสุดเพิ่งหนีกลับบ้านนอกไปสองคน... อะ กลับมาเรื่องซ่อมก่อน คือตอนนี้ทุกอย่างมันอยู่ในไลน์กลุ่มหมดเลยพี่ กลุ่มนึงแจ้งซ่อม กลุ่มนึงอู่ โทรกันมั่วไปหมด บางทีคนขับโทรหาช่างต้อม (ช่างใหญ่ผมอะ) แล้วน้องเมย์ที่เป็นธุรการก็ค่อยมาจดลงสมุด... สมุดจริงๆ นะพี่ สมุดนักเรียนเนี่ยแหละ

กติกาผมมีนะ ซ่อมนิดหน่อยๆ ผมให้ต้อมเคาะเลย ถ้าเยอะหน่อยก็ให้พี่วิรัช ผู้จัดการเดินรถแกดู แต่ถ้าหนักๆ พวกยกเครื่อง เปลี่ยนเกียร์เนี่ย ต้องมาถึงผม... อ้อ ผมตั้งกฎเหล็กเลยนะ คนทำเรื่องเบิกห้ามเป็นคนอนุมัติเอง เคยโดนช่างโกงอะไหล่ไปเป็นแสน เจ็บใจมาก

เรื่องอะไหล่นี่ก็รั่ว ยางนี่ตัวดี ยางหัวลากเส้นนึงก็หลายตังค์ เบิกกันยับเลย ผมไม่รู้เลยนะว่าเส้นไหนวิ่งไปกี่กิโล ยางเก่าหายไปไหนหมด... ปกติพวกผ้าเบรก ไส้กรอง ผมซื้อเจ๊หงส์กับ ส.เจริญยนต์ เป็นหลัก แต่พอของใหญ่มันต้องเทียบราคาไง

แต่พอรถเสียหน้างานทีไร กติกามันพังหมดแหละพี่ โทรหาผม "เฮียๆ รถเสีย เอาไงดี" ด่วนด้วย ผมก็เออๆ ซ่อมไปก่อน ซื้อร้านข้างทางไปเลย... สิ้นเดือนมาทีไร บัญชีเดินมาด่าผมเปิงเลย "เฮีย บิลนี้ของใคร ใครสั่งซื้อ ซื้อทำไมแพงเทียบราคาหรือยัง" ใครจะไปจำได้วะพี่ วันนึงรับกี่สาย

ผมเลยอยากได้อะไรที่มันช่วยผมหน่อย... เอาแค่รู้ว่ารถคันไหนวิ่งได้คันไหนจอดก็หรูแล้ว (อ้อ รถผมติด GPS ไว้แล้วนะ) แล้วเวลารถเสีย ให้มันส่งเรื่องตามคนอนุมัติเองตามสเต็ปมันอะ ไม่ต้องให้ผมไปนั่งไล่บี้ตามโทรหาคนนู้นคนนี้ สิ้นเดือนจะได้มีคำตอบให้บัญชีมันสักที งบซ่อมเดือนๆ นึงนี่... หูย หลายแสนอะ ตีกลมๆ ก็เยอะอยู่ ถ้าลดได้สักนิดก็คงดี จะได้มีเงินไปหมุนทำอย่างอื่นบ้าง
