## EN — English

### Card name

Operational control tower — see it whole, ask it anything, know before it breaks

### What you'll see

An asset map drawn from an ontology rather than from a spreadsheet somebody wired
up by hand. Questions asked in plain language, answered in a way you can trace
back to real records. And when a measured value crosses its threshold, the system
proposes what to do **with the reasoning that got it there** — not an answer that
simply appears.

When the model is not confident, it says so and falls back to a deterministic
rule.

### First 90 seconds

Open the map and find the point running over temperature → open the
recommendation attached to it → ask one question in plain language → then walk the
reasoning trace from raw reading to proposal.

### Call to action

Want this on your data — one KPI, zero integration to start
